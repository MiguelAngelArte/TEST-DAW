# TEST-DAW

Proyecto de prueba Git

Este es un proyecto de prueba para practicar el uso de Git y GitHub mediante ramas y commits.

🚀 Descripción

El objetivo de este repositorio es aprender a trabajar con ramas de funcionalidades (feature branches) y practicar el flujo de trabajo habitual en un proyecto de desarrollo.

🛠️ Tecnologías
Git
GitHub
Markdown
📋 Funcionalidades
Crear un repositorio de prueba.
Crear un archivo README.
Crear una rama feature-readme.
Modificar la documentación.
Hacer commit de los cambios.
Fusionar la rama con main.

Instalación

Clona el repositorio:

git clone <URL_DEL_REPOSITORIO>


Accede a la carpeta del proyecto:

cd <NOMBRE_DEL_REPOSITORIO>

Flujo de trabajo Git

Crea una nueva rama para modificar este README:

git switch -c feature-readme


Realiza los cambios que quieras en este archivo y añádelos al área de preparación:

git add README.md


Guarda los cambios mediante un commit:

git commit -m "docs: add test README"


Sube la rama al repositorio remoto:

git push -u origin feature-readme


Después, crea un Pull Request para fusionar los cambios con main.
